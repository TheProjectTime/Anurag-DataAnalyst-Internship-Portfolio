## 📁 Project Repository Links

### 1. Task 1 – Data Immersion & Wrangling

**Objective:** Understand the dataset, identify data quality issues, and prepare clean data for further analysis.

**Key Activities:**
- Understanding the dataset and preparing a data dictionary.
- Identifying missing values and duplicate records.
- Performing data quality checks.
- Cleaning and preparing the dataset using Python.
- Documenting the data cleaning process.

🔗 **GitHub Repository:** [ApexPlanet Task 1](https://github.com/TheProjectTime/ApexPlanet-Task-1-Data-Wrangling)

### 2. Task 2 – Exploratory Data Analysis (EDA)

**Objective:** Explore the cleaned dataset and identify useful patterns, trends, and business insights.

**Key Activities:**
- Performing exploratory data analysis.
- Calculating descriptive statistics.
- Analysing sales, products, customers, and categories.
- Creating visualizations using Python.
- Performing SQL-based analysis and identifying business insights.

🔗 **GitHub Repository:** [ApexPlanet Task 2](https://github.com/TheProjectTime/ApexPlanet-Task-2)

### 3. Task 3 – Deep-Dive Analysis & Interactive Dashboarding

**Objective:** Perform detailed business analysis and develop an interactive dashboard to communicate important performance indicators.

**Key Activities:**
- Defining and calculating key performance indicators (KPIs).
- Analysing monthly sales performance.
- Identifying high-performing products, categories, and cities.
- Creating an interactive dashboard using Microsoft Power BI.
- Presenting business findings through visualizations.

🔗 **GitHub Repository:** [ApexPlanet Task 3](https://github.com/TheProjectTime/ApexPlanet-Task-3)

### 4. Task 4 – Data Storytelling & Statistical Validation

**Objective:** Convert analytical findings into a business narrative and validate selected findings using statistical methods.

**Key Activities:**
- Developing a business story from sales analysis.
- Preparing a professional PowerPoint presentation.
- Performing hypothesis testing using Python.
- Applying Welch's Independent-Samples T-Test.
- Interpreting p-values and confidence intervals.
- Providing data-driven business recommendations.

🔗 **GitHub Repository:** [ApexPlanet Task 4](https://github.com/TheProjectTime/ApexPlanet-Task-4)
